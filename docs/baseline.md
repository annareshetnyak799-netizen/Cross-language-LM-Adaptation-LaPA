# Baseline: zero-shot direct answer, MMLU-ProX-Lite RU

## Задача

Оценка готовой (frozen) языковой модели на вопросах с выбором ответа
на русском языке — без дообучения, без демонстраций-примеров, без
запроса рассуждения перед ответом.

## Конфигурация

- Модель: Qwen3.8-27B, квантование NF4 (double quant), вычисления BF16
- Железо: A100 40GB, batch=1, concurrency=1, greedy decoding
- Данные: `li-lab/MMLU-ProX-Lite`, подмножество RU — 70 validation + 588 test
- Промпт: один user-message, вопрос и все варианты ответа полностью,
  без few-shot примеров
- Ответ модели: строго `Ответ - (X)`, максимум 32 новых токена

## Результат

| Метрика | Значение |
|---|---|
| Accuracy (588 test) | **56.29%** (331/588) |
| Wilson 95% CI | 52.26–60.25% |
| Extraction rate | 100% |
| Empty / truncated ответы | 0 |
| E2E, mean / p95 | 1.087 с / 1.311 с |

Результат независимо пересчитан из сырых логов и совпал с исходной сводкой.
Полная сводка исходного прогона (качество по предметам, распределения
времени, длины входа) —
[`results/baseline_original_summary.json`](../results/baseline_original_summary.json).

## Воспроизведение в ноутбуке

Отдельный прогон упрощённой версии пайплайна:
[`notebooks/baseline-mmluprox-ru.ipynb`](../notebooks/baseline-mmluprox-ru.ipynb),
сырые результаты по каждому вопросу —
[`results/baseline_results.json`](../results/baseline_results.json).

| Метрика | Исходный прогон | Ноутбук |
|---|---|---|
| Accuracy (588 test) | 56.29% (331/588) | 56.12% (330/588) |
| Wilson 95% CI | 52.26–60.25% | 52.08–60.08% |
| Extraction rate | 100% | 100% |
| Входные токены, mean | 297.02 | 297.02 |
| E2E, mean / p95 | 1.087 с / 1.311 с | 1.215 с / 1.424 с |
| TTFT, mean | 0.335 с | 0.602 с |
| TPOT, mean | 0.192 с | 0.157 с |

- Длины входа совпали на всех 588 вопросах: промпт и chat template те же.
- Текст ответа совпал в 564 из 588 вопросов. В 14 выбрана другая буква
  (5 правильных ответов потеряно, 4 приобретено, итого −1). Это в пределах
  шума greedy-декодирования при другом численном окружении: ноутбук не
  включает детерминированные режимы и закреплённые ядра исходного прогона.
- Тайминги зависят от окружения. В ноутбуке prefill медленнее (доля TTFT
  в E2E 50% против 31%), decode быстрее; причина не установлена. GPU и
  версии библиотек в этом прогоне не записаны (ячейка сохранения теперь
  записывает их).
- Поэтому скорость адаптированного входа нужно сравнивать с baseline
  только парно, в одном окружении.

## Ограничения

- Один seed, одна GPU-сессия — устойчивость числа по повторам не проверялась.
- Это не воспроизведение официальной таблицы бенчмарка (там — 5-shot
  с рассуждением перед ответом); числа между этими двумя протоколами
  не сравнимы напрямую.
- Baseline используется как опорная точка для сравнения с адаптированными
  вариантами входа.
