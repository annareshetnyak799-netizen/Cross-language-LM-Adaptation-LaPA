# Результаты MMLU-ProX RU

GPU: A100 40 GB, Colab, lm-evaluation-harness.
Ниже — chat, native thinking off, лимит 2048 новых токена.

## Основная выборка: 560 вопросов

Qwen3.8-27B-FP8, BF16-вычисления через Marlin.
Одинаковые вопросы во всех трех прогонах: по 40 на 14 предметов.
Это подвыборка MMLU-ProX RU, не полный benchmark.

| Режим | Инструкция | Верно | Accuracy (95% CI) | Время оценки |
| --- | --- | ---: | --- | ---: |
| 5-shot | Объяснения разрешены | 417/560 | **74.46%** (71.07–77.86%) | 7:24:43 |
| 0-shot | Только краткий ответ | 356/560 | **63.57%** (59.64–67.32%) | 0:13:25 |
| 5-shot | Только краткий ответ | 372/560 | **66.43%** (62.50–70.18%) | 0:18:00 |

Время без установки, загрузки модели и warmup.
Thinking off не запрещает обычные объяснения в ответе.

- Исходный 5-shot: 35 ответов без извлеченной буквы на лимите 2048;
  все учтены как ошибки.
- Краткие режимы: все ответы распознаны, лимит не достигнут.
  Допустимы `Ответ - D` и `Ответ - (D)`.
- При краткой инструкции 5-shot лучше 0-shot на **2.86 п.п.**
  (парный 95% CI: +0.18…+5.54).
- Краткий 5-shot потерял **8.04 п.п.** относительно исходного.
  Сокращение времени не сохранило качество baseline.

[Ноутбук исходного 5-shot](baseline-mmluprox-ru-chat-5shot-fp8-560.ipynb).
[Ноутбук парного краткого 0/5-shot](baseline-mmluprox-ru-chat-strict-560.ipynb):
одна загрузка модели, два режима, 1120 ответов.

## Предварительные проверки

| Выборка | Режим | Верно | Время оценки |
| --- | --- | ---: | ---: |
| 28 test | NF4, 5-shot, объяснения разрешены | 21/28 (75.00%) | 34:26 |
| Те же 28 test | FP8, 5-shot, объяснения разрешены | 22/28 (78.57%) | 17:23 |
| 14 calibration | FP8, 0-shot, объяснения разрешены | 8/14 | 23:19 |
| Те же 14 calibration | FP8, краткий 0-shot | 8/14 | 20 с |
| Те же 14 calibration | FP8, краткий 5-shot | 9/14 | 28 с |

Эти вопросы не входят в 560. NF4 и FP8 использовали разные движки,
малый прогон не доказывает преимущество FP8. Calibration — технический
замер, не итоговая оценка качества.

Ноутбуки на 28 вопросов: [NF4](baseline-mmluprox-ru-chat-5shot.ipynb),
[FP8](baseline-mmluprox-ru-chat-5shot-fp8.ipynb).

## Покрытие рекомендаций ментора

Выполнены chat 0-shot/off и chat 5-shot/off. Сопоставимая пара на 560
есть только для краткой инструкции. 0-shot с объяснениями проверен
только на calibration; на 560 не запускался.

Остаются: official CoT 0/5-shot, chat thinking on 0/5-shot,
Franken baseline и сравнение с собственной адаптацией в этих режимах.
Полный MMLU-ProX RU и более крупная модель не оценены.
Просмотренный test не используем для подбора параметров.
