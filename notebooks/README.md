# Результаты MMLU-ProX RU

GPU: A100 40 GB, Colab, lm-evaluation-harness.
Прогоны на 560/335 — chat, native thinking off.
Во всех описанных прогонах лимит — 2048 новых токена.

## Основная выборка: 560 вопросов

Qwen3.8-27B-FP8, BF16-вычисления через Marlin.
Одинаковые вопросы во всех трех прогонах: по 40 на 14 предметов.
Это подвыборка MMLU-ProX RU, не полный benchmark.

| Режим | Инструкция | Верно | Accuracy (95% CI) | Время оценки |
| --- | --- | ---: | --- | ---: |
| 5-shot | Объяснения разрешены | 417/560 | **74.46%** (71.07–77.86%) | 7:24:43 |
| 0-shot | Только краткий ответ | 356/560 | **63.57%** (59.64–67.32%) | 0:13:25 |
| 5-shot | Только краткий ответ | 372/560 | **66.43%** (62.50–70.18%) | 0:18:00 |

Время без установки, загрузки модели и warmup.
Thinking off не запрещает обычные объяснения в ответе.

- Исходный 5-shot: 35 ответов без извлеченной буквы на лимите 2048;
  все учтены как ошибки.
- Краткие режимы: все ответы распознаны, лимит не достигнут.
  Допустимы `Ответ - D` и `Ответ - (D)`.
- При краткой инструкции 5-shot лучше 0-shot на **2.86 п.п.**
  (парный 95% CI: +0.18…+5.54).
- Краткий 5-shot потерял **8.04 п.п.** относительно исходного.
  Сокращение времени не сохранило качество baseline.

[Ноутбук исходного 5-shot](baseline-mmluprox-ru-chat-5shot-fp8-560.ipynb).
[Ноутбук парного краткого 0/5-shot](baseline-mmluprox-ru-chat-strict-560.ipynb):
одна загрузка модели, два режима, 1120 ответов.

## Парное сравнение: 335 вопросов

0-shot с объяснениями остановлен по ресурсам на 335 из плановых 560.
Исходный 5-shot пересчитан на **те же вопросы**, без нового GPU-прогона.
В обоих режимах объяснения разрешены, native thinking выключен.

| Метрика | 0-shot | 5-shot |
| --- | ---: | ---: |
| Верно | 237/335 | 238/335 |
| Accuracy | **70.75%** | **71.04%** |
| Macro accuracy | 70.77% | 71.05% |
| Без извлеченной буквы | 54 | 25 |
| Достигнут лимит 2048 | 50 | 25 |
| Время оценки без подготовки | 9:38:42 | 4:51:35 |

Разница macro (5−0): **+0.28 п.п.**, парный 95% CI **−3.33…+4.14**.
Уверенного преимущества по точности нет; эквивалентность не доказана.
0-shot генерировал примерно вдвое больше выходных токенов.
Время описательное, не измерение аппаратного ускорения.

Это анализ частичного прогона после остановки по ресурсам.
13 предметов по 24 вопроса, psychology — 23. Интервал условен для этих
335 и не учитывает остановку по времени; полного результата на 560 нет.

[Ноутбук 0-shot с объяснениями](baseline-mmluprox-ru-chat-0shot-fp8-560.ipynb).
Код проверен на A100: 335 ответов, штатная остановка и экспорт.
Продолжение в новой среде на GPU не проверено. Ноутбук сохраняет исходный
план на 560 вопросов; результат на 335 получен остановкой по ресурсам.

5-shot и достаточность лимита для thinking на calibration.

## Покрытие экспериментов

На основной выборке выполнены **2 из 6 режимов**: chat 0-shot/off и chat 5-shot/off.
С краткой инструкцией оба оценены на 560 вопросах; с разрешенными
объяснениями парное сравнение выполнено на 335.
Краткая инструкция — вариант prompt, а не отдельный режим таблицы.

Для предварительной матрицы планируем **одни и те же 335 вопросов
во всех шести режимах**. Готовые ответы берем из сохраненных прогонов.
Calibration остается отдельным набором. Такой объем — предварительная
оценка, не гарантия обнаружения небольших различий.

Остальные четыре режима прошли calibration; на 335 еще не запускались.
Franken baseline и сравнение с собственной адаптацией — отдельный этап.
Полный MMLU-ProX RU и более крупная модель не оценены.
Просмотренный test не используем для подбора параметров.
