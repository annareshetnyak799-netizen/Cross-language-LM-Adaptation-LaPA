# Cross-language LM Adaptation (LaPA)

## Цель

**Zero-shot / zero-cost адаптация языковой модели под новый язык:** добиться
выигрыша в скорости за счёт экономии токенов без снижения качества на
ключевых бенчмарках.

Целевой ориентир — подключать новый язык без отдельного дообучения модели
под него и без дополнительных затрат, которые перекрывают выигрыш от более
компактного представления.

## Идея

Исследуем гипотезу: модель может опираться на общие для разных языков
концепты, а токенизатор — выступать интерфейсом между языком и этими
представлениями. Можно ли изменить этот интерфейс, сохранив знания и
способности самой модели?

**Semantic IR и Latent Concept Models** — абстрактная целевая картина:
работа с концептами, менее зависимыми от конкретного языка и его
токенизации. Это исследовательский ориентир, а не уже достигнутое свойство
системы.

## Что исследуем

- Токенизацию и компактные представления: как передавать тот же смысл
  меньшим числом токенов.
- Межъязыковой перенос: как подключать новый язык без отдельного обучения
  под него.
- Сохранение качества на ключевых бенчмарках и реальное ускорение всего
  pipeline с учётом стоимости преобразования входа.

## Где мы сейчас

Зафиксирован воспроизводимый **baseline**: замороженная Qwen (NF4),
zero-shot direct answer на **MMLU-ProX-Lite RU** — 56.29% accuracy
(331/588, Wilson 95% CI 52.26–60.25%), среднее время ответа ~1.09 с.
Отдельный прогон в ноутбуке воспроизвёл результат в пределах одного
вопроса: 56.12% (330/588).

Поверх baseline проверены две гипотезы адаптации входа — обе не прошли
заранее заданные пороги (`no_go`):

- расширение словаря токенизатора новыми целыми словами — не дало
  сокращения токенов на реальных данных;
- объединение существующих токенов и обучение эмбеддингов только для
  них — сокращение входа оказалось недостаточным на MCQ-вопросах.

Ранее также проверен подход через multilingual encoder и projector к
замороженной LLM (semantic IR) — не дал нужного сочетания качества и
скорости (одна из экспериментальных веток, а не весь scope проекта).

Следующий шаг — короткая проверка, есть ли в принципе запас по времени
для выигрыша от сжатия входа в текущем режиме задачи (короткие вопросы,
короткий ответ), прежде чем искать новый механизм адаптации.

## К чему можно подключиться

Исследование токенизаторов и semantic IR, эксперименты с межъязыковым
переносом, бенчмарки качества и профилирование инференса.
